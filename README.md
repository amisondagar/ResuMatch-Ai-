# RESUMatch.ai

Smart Resume Screening Powered by Artificial Intelligence

---

## Project Overview

RESUMatch.ai is a web application that helps HR recruiters screen resumes faster using AI. Instead of manually reading through hundreds of resumes, recruiters can upload resumes and a job description, and the system automatically reads, understands, and scores each resume based on how well it matches the job requirements.

---

## Problem

Recruiters receive hundreds of resumes for a single job opening. Going through each one manually to check skills, experience, and education takes a lot of time — often several days — and it's easy to miss good candidates.

## Solution

RESUMatch.ai uses AI to read resumes automatically, compare them with the job description, and give each candidate a match score. This helps recruiters instantly see who is the best fit, without reading every resume by hand.

---

## Features

- Upload resumes (PDF/DOCX) — single or multiple at once
- AI automatically extracts name, email, phone number, skills, education, and experience
- Calculates an ATS match score for each resume based on the job description
- Automatically checks each resume against all job descriptions and picks the best match
- Ranks candidates from highest to lowest score
- Analytics dashboard with charts (total candidates, shortlisted, rejected, average score, etc.)
- Download reports as PDF or CSV
- Bookmark candidates and add recruiter notes
- Manually mark candidates as Pending, Shortlisted, Interview, or Rejected
- Dark and light mode
- Secure login and registration system

---

## Tech Stack

**Backend:** Python, Flask
**Database:** SQLite
**AI / NLP:** spaCy, Sentence Transformers, scikit-learn
**Resume Reading:** pdfplumber, PyPDF2, python-docx
**Login Security:** bcrypt
**Reports:** fpdf2, pandas
**Charts:** Plotly.js
**Frontend:** HTML, CSS, JavaScript
